# Day 5 — JavaScript Solutions

This folder contains solutions for the Day 5 internship material.

- **Day 5.1:** Template literals, optional chaining, nullish coalescing, logical operators, and default parameters.
- **Day 5.2:** JSON conversion, error handling, filtering, mapping, sorting, and reduce.
- **Day 5.3:** localStorage, sessionStorage, safe JSON parsing, and task-list logic.
- **Day 5.4:** Workbook answers and a persistent task manager mini project.

## Run the examples
- Most `.js` task files can be run with Node.js using `node filename.js`.
- Browser storage examples and the task manager must run in a browser because they use `localStorage` and `sessionStorage`.
- To run the mini project, open `Day 5.4/index.html` in your browser.

Never store passwords or secret API keys in browser storage.
